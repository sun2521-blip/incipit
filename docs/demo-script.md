# Demo script (2 to 3 minutes)

A walkthrough of the live site, https://incipit-five.vercel.app, for recording a short screen capture. Open the site a minute before recording so the free API is awake, and use a fresh browser window so the profile and shortlist start empty.

## 1. The problem (15 seconds)

"Finding a first open-source issue you can actually do takes hours. Labels like *good first issue* are everywhere and say little. Incipit finds them and tells you, honestly, which ones might fit you, and why."

## 2. Discovery (30 seconds)

- Scroll to **Find your starting point**. Point out that these are live GitHub issues, with each repository's language and stars.
- Type a keyword, such as `docs`. Show the placeholders while it searches, then the results.
- Clear it, then type `owner/repo` for a project you know (for example `pallets/flask`) to show one project's beginner issues.

## 3. The score is explained (30 seconds)

- Open **Your profile**, add a language (`Python`) and a topic (`testing`), and tick a task type. Watch the order and the Fit scores change.
- Open **Why this score** on a card: each signal's points, weight and reason. If an issue shows a penalty (assigned, or a busy thread), point it out.
- Say what the score is not: "It never promises an issue is easy or unclaimed."

## 4. The dossier (45 seconds)

- Click a card's title.
- **On GitHub:** facts checked live, with the time they were checked: state, assignees, comments, labels, the repository's language, licence and contributing guide.
- **How it may fit you:** the inferred task type and the score, labelled as Incipit's inference.
- **A general checklist:** labelled as general, not checked against this repository.
- Click **Save to shortlist**, then **Continue on GitHub** to show it opens the real issue.

## 5. The shortlist persists (15 seconds)

- Go back, scroll to **Your shortlist**, then refresh the page: it is still there.

## 6. Close (15 seconds)

"Built with Next.js and FastAPI on free hosting, no AI required. The ranking was checked against real issues, and every score explains itself. Every contribution has a beginning."
